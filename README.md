# 📊 Superstore Sales Analysis - Data Analyst Project

## 📌 About This Project
This project analyzes Superstore sales data to uncover key business insights like top-selling products, most profitable regions, and loss-making categories. This is my first step towards a Data Analyst career.

## 🎯 Objective
- To find sales & profit trends
- To identify top customers and products
- To find loss-making areas for business improvement

## 🛠️ Tools & Technologies Used
- Python
- Pandas & Numpy for data cleaning
- Matplotlib & Seaborn for visualization
- Jupyter Notebook

## 🔍 Key Insights
- Technology category has the highest sales
- West region generates the most profit
- Tables and Bookcases are in loss and need attention
- Sales are growing year by year

## 📈 What I Learned
- Data Cleaning & Data Exploration (EDA)
- Data Visualization
- Business Storytelling with Data
